# Ứng Dụng Quản Lý Học Sinh

## Cách chạy dự án

### 1. Khởi động MongoDB (Docker)
```bash
cd backend
docker-compose up -d
```

### 2. Chạy Backend (Express)
```bash
cd backend
npm install
npm start
```
Backend chạy tại: http://localhost:5000

### 3. Chạy Frontend (React)
```bash
cd student-management
npm install
npm start
```
Frontend chạy tại: http://localhost:3000
