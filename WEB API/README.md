# Bài tập: CRUD Web Application

## Đề bài

Xây dựng một ứng dụng web CRUD sử dụng Fetch hoặc Axios để tương tác với API: https://jsonplaceholder.typicode.com/users

## Yêu cầu

### Các tính năng bắt buộc:

- **Read**: Hiển thị bảng danh sách users với các thông tin: name, email, phone
- **Create**: Form để thêm user mới
- **Update/Edit**: Form chỉnh sửa hoặc popup form
- **Delete**: Xóa user khỏi bảng
- **Search**: Lọc users theo tên
- **Pagination**: Phân trang

## Lưu ý

- Sử dụng **async/await**, không dùng `.then()`
- Cập nhật UI thủ công sau các thao tác POST/PUT/DELETE
- Xử lý lỗi (error handling)

## Cách chạy project

```bash
cd react-crud
npm install
npm run dev
```
